# DSA Study Notes

This repository is a growing personal knowledge base for Data Structures and Algorithms. It is designed to hold notes, patterns, and study material across multiple topics, not just sliding window or graph theory.

## Purpose

The goal of this repo is to provide a structured place to organize:

- core DSA concepts and interview patterns
- topic-specific notes such as arrays, graphs, and problem-solving approaches
- personal study material that can be revisited during preparation
- future additions as new topics are learned

## Repository Structure

The repository is organized by topic so it remains easy to navigate as it grows:

- [topics/problem-solving](topics/problem-solving) - general problem-solving mindset and approach notes
- [topics/arrays](topics/arrays) - array-based techniques and patterns
- [topics/graph-theory](topics/graph-theory) - graph theory notes, traversals, and problem sets
- [scripts](scripts) - helper scripts for working with the notes

## How to Use

1. Open the markdown files in any editor that supports preview.
2. Browse by topic folder depending on the subject you want to study.
3. Add new notes in the relevant topic folder as your learning expands.
4. Keep the structure consistent so the repository stays easy to navigate.

## Note

This repo is primarily a study notebook, so the content is intentionally practical and focused on learning and revision.
